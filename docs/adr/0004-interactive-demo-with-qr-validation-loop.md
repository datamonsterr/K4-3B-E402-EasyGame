# ADR 0004: Interactive Demo with QR Validation Loop

We decided to integrate a dedicated post-experience completion screen featuring both direct Google Forms links and high-visibility QR code rendering directly inside the web demo.

User testing and hackathon rubric criteria mandate collecting immediate empirical feedback from willing users (both Students and Lab Coaches). Rather than assuming evaluators will remember external survey links, completing a test flow in the demo webapp automatically offers a concluding modal/view with role-specific Google Form URLs and instant mobile-scannable QR codes. This closes the feedback loop in real time, logging tester sentiment and opt-in consent for ongoing cohort validation.
